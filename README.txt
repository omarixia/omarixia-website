OMARIXIA Identity Services website v2
Bilingual static website for individuals and businesses.

Not yet included: live NIN/BVN/face verification, payments, customer accounts, request tracking, or admin dashboard.

Before selling verification:
- Obtain written JanKado approval for each selected API and commercial resale.
- Confirm provider prices, fixed customer prices, service terms and refunds.
- Confirm lawful authority, consent wording and data protection requirements.
- Build a secure server-side backend. Never put API keys in public HTML/JavaScript.
- Add secure payments, audit logs, access controls and retention/deletion processes.
- Never collect PINs or OTPs.

To update GitHub Pages:
1. Open repository https://github.com/omarixia/omarixia-website
2. Replace the root index.html with this index.html.
3. Commit to main. GitHub Pages redeploys automatically.
